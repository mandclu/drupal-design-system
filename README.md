# Drupal Design System
A design system for use with Claude Design, implementing Drupal's design system

This was developed using the Drupal [Brand Portal](https://drupal.widencollective.com/portals/gfvztttq/BrandPortal#641bb0aa-56eb-4645-b192-12406c7ec131) and [Figma Brand Board](https://www.figma.com/design/tKYim76bnDZAyWubUi3sVv/New-Drupal-Brand---Drupal.org-Design?node-id=6021-22741&p=f&t=VRUhbiQBVSlCn7Sb-0). Suggestions for improvements or additions are welcome.
